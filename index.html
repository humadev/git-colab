Interactive Git Collaboration Lab Guide

Check off each step as you complete the lab. Your progress is saved locally in your browser.

  • git clone <repo-url>
    git status
  • git switch -c feat/add-yourname
  • git diff
  • git add index.html
    git commit -m "feat: add <Your Name> profile card"
  • git pull --rebase origin main
    git push -u origin feat/add-yourname
  • Anatomy of a Merge Conflict
    <<<<<<< HEAD
<p id="class-motto">"Ship small PRs every day!"</p>
=======
<p id="class-motto">"Test twice, merge once!"</p>
>>>>>>> feat/motto-update

    How to fix it: Keep the code you want (or combine both), delete all three marker lines (<<<<<<<, =======, >>>>>>>), then run git add index.html and git commit (or git rebase --continue if rebasing).
